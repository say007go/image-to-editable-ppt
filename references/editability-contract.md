# 可编辑性契约

## 对象类型

### 文本

- 每段可修改文字使用独立 TextBox；同一文本中字号、颜色、字重或对齐不同的部分使用独立 Text Run 或文本框。
- 内容逐字保真，保留大小写、标点、空格、显式换行和数字单位。
- 设置字体时应显式处理页面实际出现的字符脚本（如 eastAsia、latin 等）；发生字体替代时同步检查字宽、字重、行距和换行，不强制不同脚本使用同一个字体。
- 所有 TextBox 默认设置 `word_wrap=false` 并预留 30~100pt 动态右侧内边距；多行正文通过显式换行、拆分文本框或调整高度保留输入中的断行，不以缩小字号掩盖溢出。

### 形状

- 色块、卡片、背景带、圆角容器、路径、分割线和其他图形主体均使用独立原生 Shape；复合图形的主体路径与可见局部构件分别保留。
- 每个形状都应有可检查的填充、描边、线宽、透明度、坐标和层级。
- 虚线边框使用带原生 dash 属性的无填充矩形或相应几何 Shape。
- 形状可以按语义分组，但不得把需要独立调整的文本、图形或图片合并成单一对象。

### 图标

- 标准图标可以采用独立 SVG 矢量对象，但必须记录图标库、图标 ID、许可证、颜色和编辑级别。
- 默认要求图标能够独立选中、移动、缩放和替换；这属于对象级可编辑，不等同于 SVG 内部每条路径都能单独编辑。
- 用户明确要求每条线独立编辑时，将可可靠转换的路径拆为原生 Shape；无法可靠转换的部分必须披露，不得为了增加 Shape 数量而牺牲轮廓质量。

### 图片

允许保留的图片仅限输入页面中无法合理拆解的复杂局部视觉资产，例如照片、产品渲染图或三维插画，并且应裁切为不含文字的局部。输入页面本身不得作为整页背景。

## 坐标与层级

为每个对象保存统一坐标系中的 X、Y、宽度和高度，并记录 z-order。转换画布比例时重新计算空间关系，不直接把所有对象等比例拉伸。

对于具有中心、边界或路径关系的图形，应保存当前页面实际存在的中心点、端点、控制点、半径（若确实存在）、保护区以及构件之间的关系；不存在的关系不得凭经验补设。标签默认放在实际留白中，不以白色文本框遮挡图形或虚线。

## 失败判定

出现以下任一情况，不能判定为完成：

- 整页只有一张输入图片或一张 SVG；独立局部 SVG 图标不触发该失败判定。
- 主要文字无法单独选中和修改。
- 主要色块、边框、图形或表格被合并为不可编辑图片。
- 图形只剩不完整的主体轮廓，或局部构件与主体接缝明显破坏视觉连续性；自定义路径的质量应以当前页面轮廓为准，不能仅因使用了 Custom Geometry 就判定不合格。
- 输出文件无法打开，或渲染后出现大面积错位、截断、遗漏或遮挡。
