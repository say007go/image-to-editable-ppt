# 变换模块

变换模块只在用户明确提出时启用。基础重构完成后再执行变换，并对变换后的结果重新渲染和验收。

## 模块选择规则

| 用户目标 | 模块 | 必要输入 |
|---|---|---|
| 使用企业 VI 或指定品牌色 | `palette_override` | 品牌主色、辅色或品牌规范 |
| 改为 16:9、4:3 或自定义比例 | `canvas_override` | 目标宽高或目标比例 |
| 两者都提出 | 两个模块 | 两类参数都必须明确 |

未提供品牌颜色时，不自行猜测；未指定特殊目标比例时，基础重构采用核心提示词规定的 16:9 默认画布；输入页面为 4:3 或其他特殊比例时，按核心提示词自适应留白，不做拉伸变形。

## 模块执行顺序

```text
基础保真重构
    ↓
建立基础版视觉基线
    ↓
画布比例变换
    ↓
品牌配色变换
    ↓
最终渲染与验收
```

## 品牌配色变换

下面的模块提示可以直接追加到核心重构协议之后。使用时只替换用户提供的颜色参数，不改变对象层级、文本内容和相对位置。

执行前必须替换必填占位符；未提供的可选颜色参数整行删除，不得把占位符或示例值直接写入 PPTX。

```markdown
# Color Override（品牌配色一键覆盖）
- 仅将用户明确授权的颜色角色映射为企业品牌标准色，不改变对象几何、层级、文字内容和相对位置：
  - 主品牌色：{{PRIMARY_COLOR}}（用于输入页面中承担主视觉角色的对象）
  - 重点强调色：{{ACCENT_COLOR}}（可选，用于输入页面中承担强调角色的对象）
  - 背景与底板色：{{BACKGROUND_COLOR}}（可选）
  - 文字色：{{TEXT_COLOR}}（可选；深色底上的文字应由 {{LIGHT_TEXT_COLOR}} 提供足够对比度）
- 未提供的颜色角色保留输入页面取样结果，或仅按可读性与用户给定品牌规范推导并记录；不得把示例占位符当作实际颜色。
- 照片、复杂局部图片和用户明确要求保留的语义色不参与替换，除非用户另行授权。
- 保持输入页面的层级架构与相对位置关系不变，仅执行可追溯的颜色映射。
```

执行后检查：同一语义角色的对象是否使用同一颜色映射；文字对比度是否足够；颜色变化是否误改了照片或用户要求保留的局部图片。

### 图标矢量对象的配色处理

当页面采用独立 SVG 图标时，品牌配色变换应只修改图标的 `stroke`、`fill` 或等效矢量颜色属性，保持图标路径、viewBox、线宽和比例不变。若运行环境无法安全改写 SVG，应重新从同一图标库生成目标颜色的资源，不得把图标转为低分辨率位图。

## 画布比例变换

下面的模块提示可以直接追加到核心重构协议之后。使用时替换目标画布参数。

执行前必须替换目标宽高或比例占位符，并明确单位；目标未确定时不要执行此模块。

```markdown
# Canvas Override（画布比例动态转换）
- 将整体画布调整为用户指定的目标宽高或目标比例：{{TARGET_WIDTH}} × {{TARGET_HEIGHT}}；若用户指定标准 16:9，则采用 13.333 × 7.5 英寸；若用户指定 4:3 或其他比例，则按对应参数执行；
- 根据对象边界、页面锚点和容器之间的实际关系重新计算空间分布，保持层级和可确认的对齐关系，不机械复制或拉伸所有对象；
- 严禁对文本框或图形进行机械拉伸；新增或减少的空间通过重新分配间隙和留白适配，确保排版疏密得体。
```

执行后检查：文字和图形是否保持可编辑；对象是否被机械拉伸；页面是否出现新的溢出、重叠或过度留白。
