# 叠加比对与坐标校准协议

叠加比对是页面级 QA 的定位工具，不是把渲染图重新贴回 PPT，也不是用单一像素相似度替代对象审计。它的任务是回答两个问题：哪个对象偏了多少，以及应当改对象的坐标、尺寸、层级还是文字排版。

## 1. 统一坐标系

1. 将输入页面和 PPT 渲染页转换到同一像素画布；优先保持长宽比，出现比例不一致时采用等比缩放加白色留边，并记录缩放因子与偏移量。
2. 保存源图、渲染图、50% 透明叠加图、差异热图和机器可读的统计结果。
3. 颜色替换、字体替换或抗锯齿会制造大量像素差。颜色变换场景优先比对边缘、轮廓、连通区域、对象框和关键 ROI，不把整体颜色差异直接判定为坐标错误。

若输出画布与输入页面比例不同，先按用户授权的目标比例生成目标基线，再与渲染页进行同画布比对；不得把比例变换产生的预期留白或重新分布误判为对象错位。

## 2. 比对产物

```text
overlay.png       源图与渲染图半透明叠加，用于找整体偏移和双影
difference.png    逐像素差异增强图，用于找遗漏、遮挡、溢出和尺寸差
metrics.json      尺寸、归一化参数、差异比例、差异区域和阈值记录
```

判断顺序固定为：先看整体锚点，再看容器边界，再看主图形轮廓，最后看图标、文字和内边距。对于换色页面，轮廓层和安全区层优先于颜色层。

如果运行环境没有现成的图像比对工具，可以按以下抽象接口实现：

```text
normalize_to_canvas(source, render, policy) -> source_norm, render_norm, transform
blend(source_norm, render_norm, alpha=0.5) -> overlay
diff(source_norm, render_norm, threshold) -> difference, metrics
```

## 3. 从双影反推修复动作

| 叠加现象 | 优先判断 | 修复动作 |
|---|---|---|
| 同一轮廓出现等距双影 | 对象整体 X/Y 偏移 | 只平移对应对象或同一对象组 |
| 外框基本重合、内框出现双影 | 宽高、内边距或线宽不一致 | 先修宽高，再修内边距和线宽 |
| 文字出现多重重影、形状边缘基本重合 | 字体、字号、字重、换行或文本框宽度不一致 | 先校准字体映射和文本框，再调整位置 |
| 只有某一侧出现红色/蓝色边带 | 溢出、裁切或安全边距不足 | 缩小文本框或增加对应侧安全边距 |
| 目标轮廓完全没有对应影像 | 对象遗漏、被遮挡或被合并 | 回到对象清单，补建并检查 Z 顺序 |
| 颜色差异覆盖整块区域但轮廓重合 | 品牌色变换或取色差异 | 不移动对象，改走颜色抽样与变换规则 |
| 文字周围出现规则矩形色块、图形在色块边缘被截断 | 文本框用白色填充掩盖了图形重叠 | 去除文本框填充，调整标签位置或图形保护区；仅当输入页面确有底板时保留独立底板 |

## 4. 坐标校准顺序

按以下顺序校准，避免一个局部修复破坏全页关系：

1. 画布比例和页面外边距；
2. 标题带、卡片、底栏等大容器；
3. 当前页面的主图形、路径性/方向性图形、连接线和其他高风险几何对象；
4. 图标和编号；
5. 标题、标签、正文和脚注；
6. 文本框内边距、自动换行和局部层级。

每轮只提交一组同类坐标补丁，例如“同一图形组整体平移＋边界调整”或“某一列文字的右/下内边距修正”。重新渲染后再判断，最多进行三轮有效纠偏；同一缺陷连续两轮没有实质改善时，停止重复尝试，不得继续盲目平移。

## 5. 图形安全区

叠加比对必须与对象框规则同时使用：

- 主图形的可见轮廓不得进入标题、副标题、相邻容器或其他受保护文字的安全区，除非输入页面明确呈现该相交关系；
- 对存在中心、边界、路径或多组件关系的页面，按输入中实际出现的边界、路径和负空间划定保护区；只有输入证据明确支持某种内外边界或中心关系时，才记录相应的安全区；
- 标签文本默认不得与图形实体相交，且应放入预先划定的实际留白。只有输入页面明确显示白色底板或光晕时，才允许保留独立可编辑底板；不得用白底掩盖几何错误；
- 容器内的文字默认按核心提示词预留 30~100pt 动态右侧内边距，并留出适配内容高度的下边界空间，不能仅凭自动缩小字体来掩盖越界；
- 只有当输入证据表明同级对象采用同一布局规则时，才共享边距、锚点或坐标规则；否则按各自可见边界校准，不得只修最后一个肉眼可见的对象。

## 6. 与内容和结构 QA 的关系

叠加图只能证明视觉位置关系，不能证明文字可编辑、图形预设或 SVG 已经达到路径级编辑。最终结论必须同时引用：

```text
像素层：源图 / 渲染图 / 叠加图 / 差异图
对象层：文本框、Shape、SVG、层级和边界框
文件层：PPTX 包完整性、预设几何或原生自定义路径记录
```

只有三层结论一致，才能把“位置已经校准”写入验收报告。
